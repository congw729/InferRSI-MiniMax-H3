# Contributing

Keep each change within a declared loading/environment step and preserve the historical evidence. Run the documented tensor checks in an isolated environment, with explicit fixture/source/output paths under the canonical record root.

Repository smoke is separate from L0–L4 model acceptance. Formal comparisons require an accepted issue and frozen quality/performance gates before candidate search. Keep failures and software identities.

Do not commit personal paths, credentials or raw model weights. Review actual changes before publication. If commits are requested, use the contributor's configured DCO identity rather than inventing an author. Author self-review does not satisfy independent review.
